starship-jj overview

Jujutsu state in your Starship prompt

starship-jj is a custom Starship module that renders the current jj repository status directly in the shell prompt: the jj symbol, nearby bookmarks, the working-copy change description, state warnings, and change metrics.

Install / downloadSee examplesSource repository

What it reports

Bookmarks

Finds bookmarks in the current commit's ancestors, can exclude names, limit search depth, truncate names, and marks bookmarks behind the working copy with the configured ⇡ suffix.

Commit text

Shows the working-copy change description, with optional truncation, quoting, previous-description fallback, and change/commit id styling.

State warnings

Prints configured labels for conflict, divergent, hidden, immutable, and empty working-copy states.

Metrics

Shows changed files, added lines, and removed lines using a configurable template such as [{changed} {added}{removed}].

Starship wiring

Enable the module from starship.toml. This is the snippet from the project README:

format="""
...
${custom.jj}\
...
"""

[custom.jj]
command = "prompt"
format = "$output"
ignore_timeout = true
shell = ["starship-jj", "--ignore-working-copy", "starship"]
use_stdin = false
when = true

The plugin then loads starship-jj.toml from the OS config directory unless --starship-config points elsewhere. starship-jj starship config path prints that location, and starship-jj starship config default prints the default configuration.

This fork

Hot-path config loading

The fork parses TOML directly once and avoids the heavier config-crate merge path during prompt rendering.

Targeted environment overrides

Only explicit SJJ__* variables are read, avoiding a full environment scan every time Starship draws the prompt.

Opt-in dotenv

.env loading is behind the dotenv feature and release builds require STARSHIP_JJ_USE_DOTENV=1, avoiding extra prompt-time I/O by default.
