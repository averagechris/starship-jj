Prompt segments for common jj states

These examples follow the default module order from the source: symbol, bookmarks, commit description, state warnings, and metrics. The default symbol is 󱗆 , state labels come from starship-jj.toml, bookmark-ahead uses ⇡, and metrics use [{changed} {added}{removed}].

Clean working copy

󱗆 main (EMPTY) (IMMUTABLE) [0 +0-0]

The State module enables empty and immutable labels by default; metrics still render unless hide_if_empty is configured.

Described change

󱗆 main⇡ feat(pages): add overview [3 +148-0]

The Bookmarks module appends ⇡ when a found bookmark is behind the working copy; Commit truncates long descriptions to the configured width.

Conflict

󱗆 main⇡ resolve docs merge (CONFLICT) [2 +24-17]

Conflict, divergent, hidden, immutable, and empty warnings are emitted by the State module with configured text and colors.

Bookmark ahead

󱗆 release/v1⇡ pages-std⇡ chore: prepare release [1 +6-2]

Multiple matching ancestor bookmarks are separated by the bookmark separator, then followed by the global module separator.

Examples are stylized for the page; the terminal output uses ANSI styling from starship-jj.toml.
